# 3iwom.ai Website

Static website for 3iwom.ai, built from the supplied company introduction deck, AI Agent proposal deck, and NocoBase authorization PDF.

## Preview

Run a local static server from this folder:

```sh
python3 -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

## Files

- `index.html` - page structure and website copy
- `styles.css` - responsive visual system
- `script.js` - sticky header and mobile navigation
- `assets/` - selected images and logos extracted from the supplied decks
